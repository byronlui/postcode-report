## Boundaries of verification

No user token was copied into source, settings, commands, logs or packages. Real
account-authenticated EPC content was not verified in this audit: the user enters
their credential directly into the website. All such responses bypass SQLite cache.
The EPC schema was checked against government-published RdSAP 21.0.1 and SAP 19.2.0
samples. Exact-address mismatches remain blank; building age is a band, not a build
day. More than 40 automatic details are marked partial; individual cards can load
a certificate on demand. Bedrooms/bathrooms remain separately sourced, never inferred.

Catchment, Parent View and financial accounts still include official lookup routes
where no verified import exists. Google Maps timings open on Google; embedded OSRM
is a separate source and does not use Google routing data. No third-party paywalls
or proprietary school/house datasets were accessed.
